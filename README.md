

# EuroSAT — A Project Comparing Non-Learning and Learning Methods for Land-Cover Classification and Detection

A comprehensive project that compares rule-based (non-learning) approaches with deep learning methods for land-use classification and regional detection using the EuroSAT dataset.

---

##  Project Overview

This project is built on the **EuroSAT dataset**, which is derived from Sentinel-2 satellite imagery with a 10-meter ground sampling distance (GSD) and includes 10 land-use and land-cover classes.

### Project Objectives

1. **Comparative Analysis**: Systematically compare the performance of **non-learning methods (rule-based / unsupervised)** and **learning-based methods (deep learning)** for land-cover classification
2. **Region-Level Detection**: Explore region-level detection and localization strategies **without bounding-box annotations**
3. **Generalization Study**: Evaluate model generalization by testing on **cross-region or cross-season** real-world scenarios
